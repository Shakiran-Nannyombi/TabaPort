🔌 Your Exact Connections — What Goes Where

⚠ USB UNPLUGGED during all wiring. Only plug in after the final checklist.
# Your ESP32 Pin Label Physical Location on Board Wire Colour Connect To Why
1 VIN Right column, very last pin (bottom right) RED JSN-SR04T driver board VCC Gives 5V to the sensor. VIN passes USB 5V directly. Do NOT use 3V3 — sensor won't fire.
2 GND Left column top (next to USB) — use this one BLACK JSN-SR04T driver board GND + breadboard GND rail Common ground for everything — sensor, resistors, LEDs, buzzer all share this rail.
3 P5 (GPIO5) Left column, 8th pin from top (after GPIO0) BLUE JSN-SR04T driver board Trig Firmware fires a 20µs pulse here every 500ms to trigger the sensor measurement.
4 P18 (GPIO18) Left column, 9th pin from top ORANGE Middle of 1kΩ/2kΩ voltage divider (NOT directly to Echo) Reads the echo pulse. MUST go through the voltage divider first — Echo is 5V, GPIO18 max is 3.3V.
5 P25 (GPIO25) Right column, 10th pin from top GREEN 220Ω resistor → Green LED anode (long leg) Firmware drives this HIGH when water level is safe (green state).
6 P26 (GPIO26) Right column, 11th pin from top YELLOW 220Ω resistor → Yellow LED anode (long leg) Firmware drives this HIGH when water is filling the drain (yellow state).
7 P27 (GPIO27) Right column, 12th pin from top RED 220Ω resistor → Red LED anode (long leg) Firmware drives this HIGH when water is near road level (red state).
8 P14 (GPIO14) Right column, 13th pin from top PURPLE Buzzer + leg (long leg) Firmware beeps once at 2000Hz using LEDC PWM when state transitions to red.
9 GND (second one) Right column, 16th pin from top BLACK LED cathodes (short legs) + Buzzer − leg Return path for LEDs and buzzer. Use this second GND to avoid crowding the first.

⚠ Voltage Divider — Build This on the Breadboard (Mandatory)

The JSN-SR04T Echo pin outputs 5V. Your GPIO18 pin maximum is 3.3V. Without this divider you will silently damage GPIO18 over time.
JSN-SR04T Breadboard rows ESP32 Echo ──────────────── row A ──[1kΩ (brown-black-red)]── row B ──── GPIO18 (P18) (5V out) | [2kΩ (red-black-red)] | GND rail What you do physically: 1. Orange wire from JSN-SR04T Echo → breadboard row A 2. 1kΩ resistor legs span → row A to row B 3. Orange jumper from → row B to ESP32 GPIO18 (P18) 4. 2kΩ resistor legs span → row B to GND rail GPIO18 MUST connect to row B (the middle). Not to row A (the Echo side). Only have 1kΩ resistors? Use ONE for the top and TWO IN SERIES for the bottom.

✅ Final Checklist Before Plugging In USB

  • VIN (bottom right) → JSN-SR04T VCC  (red wire)
  • GND (left top) → JSN-SR04T GND + breadboard GND rail
  • P5 (GPIO5) → JSN-SR04T Trig  (blue wire)
  • JSN-SR04T Echo → 1kΩ → row B on breadboard
  • Row B on breadboard → orange jumper → P18 (GPIO18)
  • Row B on breadboard → 2kΩ → GND rail
  • P25 → 220Ω → Green LED long leg → short leg → GND
  • P26 → 220Ω → Yellow LED long leg → short leg → GND
  • P27 → 220Ω → Red LED long leg → short leg → GND
  • P14 → Buzzer + leg (long) → Buzzer − → GND
  • Second GND (right col, 16th pin) connected to LED cathodes
  • No wires near GPIO0, GPIO2, GPIO12, GPIO15
  • No wires on GPIO6,7,8,9,10,11 (internal flash pins)
  • ESP32 pressed firmly into breadboard
  • USB-C cable is a DATA cable (not charge-only)

✓ Power-on test: Plug USB. All 3 LEDs flash in turn (green → yellow → red) then one beep. That means the firmware is alive and all pins are wired correctly.
